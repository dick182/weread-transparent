作者：MΛØ

一、两个版本，任选其一
----------------------------------------------------------------
1) WeRead-Transparent-1.0.4-Portable.exe
   单文件便携版，双击即用，不用安装。
   首次启动会把程序解压到 %TEMP%\WeReadTransparent，退出后自动清理，
   所以首次打开会慢 3~6 秒，之后系统有缓存会快一些。

2) WeRead-Transparent-1.0.4-Win-x64.zip
   文件夹版，解压到任意目录，双击里面的 WeRead.exe 使用。
   启动最快，适合长期放在固定位置（桌面、D 盘、U 盘）。

二、登录
----------------------------------------------------------------
打开后就是网页版微信读书，扫码登录即可，登录态会记住。
默认数据（含登录态）保存在：
    %APPDATA%\weread-transparent

想让登录态和数据跟着 U 盘走？
在 exe 同目录新建一个空文件，文件名必须是：portable.txt
再次启动，数据就会写到 exe 旁边的 data\ 文件夹。
（删掉 portable.txt 即回到 %APPDATA% 目录）

三、快捷键
----------------------------------------------------------------
    F12      切换透明（沉浸）模式
    Alt+X    切换无图模式（隐藏封面与正文插图）
    Alt+Z    老板键：窗口显示 / 隐藏
    Alt+B    添加 / 移除书签（阅读页用，生效于当前页）
以上全部可以在顶部面板「设置」里改键位和生效范围（全局 / 应用内 / 关闭）。

面板的唤出方式：鼠标移到窗口顶部中间区域，面板会浮现；
把鼠标移开就自动隐藏；按 Esc 可以让面板常驻或恢复自动隐藏。

四、透明模式怎么用
----------------------------------------------------------------
透明后页面上只剩正文和插图浮在桌面上，其他界面元素全部隐藏。
翻页有三种方式：
    · 点左右两侧边缘（各 13% 宽的隐形点击区，右侧顶部 152px 让给书签）
    · 鼠标滚轮
    · ←/→ 或 PageUp/PageDown
想调文字颜色，用面板上的「白字 / 黑字」，这两个按钮只在透明模式下可用
（透明时桌面底色不可控，才需要手动定字色；普通模式直接用网站原色）。

· 添加书签：透明模式下唯一保留的网站功能。平时完全看不见，
  鼠标移到右上角（书签位置）才会出现蓝色书签图标和「点击添加书签」，
  点一下加书签、再点一下移除。
  也可以直接按 Alt+B 加 / 移除，不用去找那个按钮（普通模式下同样可用）。
  （1.0.4 修复：以前鼠标只要没精确压在那条 15px 宽的书签图标上，图标就显示成
    灰色半透明残影、位置看着也不对；现在悬停区域内恒定显示蓝色实心图标，
    鼠标一移开立即完全消失，翻页也不会闪。）
  （1.0.3 修复：鼠标移开后书签曾在上方残留闪一下。）
· 热门想法：点正文里带虚线的句子会弹出想法面板，
  面板里可以直接用滚轮浏览，不会误翻页、也不会被关掉。

五、常见问题
----------------------------------------------------------------
· 双击没反应 / 一闪就退
  检查是不是从压缩包里直接双击的，先解压出来；另外确认没有杀毒软件拦截
  （程序未做代码签名，部分安全软件会提示，属于正常现象，选择信任即可）。

· 提示端口占用 / 打不开
  本程序只用系统默认浏览器内核，不监听端口，正常不会出现；如遇异常，
  完全退出（托盘右键 → 退出）后重新打开。

· 书籍内容空白
  需要联网并登录；网络异常时程序会自动重试加载首页。

· 快捷键没反应
  可能与其他软件冲突。打开面板「设置」，把对应键位改成别的组合即可，
  冲突时会有提示；F12 这类浏览器保留键只能设为「应用内」。

· 按 Alt+B 提示「没有书签按钮」
  说明当前不在书籍正文页（比如书架页）。先打开一本书再按即可。
